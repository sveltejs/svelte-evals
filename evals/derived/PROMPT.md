Create a Svelte 5 number doubler component that uses the `$derived` rune.

The component should have a number input starting at 5, use `$derived` to calculate the doubled value, and include a button to increment the number by 1.

Use these `data-testid` attributes:

- `doubled-value`: element displaying the doubled value as `Doubled: 10`
- `increment-button`: the increment button
